# Every SBE schema id in use across the open exchange repos. An id names exactly one wire schema
# everywhere: a decoder that sees a schema id must be able to know which schema it is.
#
# One line per schema: <id> <package> <owner>:<path>
#   id       the messageSchema id attribute, 1..65535, listed once
#   package  the messageSchema package attribute, listed once
#   owner    the repo that publishes the schema file (core, match), or aeron for ids Aeron owns
#
# Every repo carries this file with the same content, and a test in each repo checks its own
# schema files, copies and id constants against it. A new schema takes a free id here, in every
# repo, before it is published.
